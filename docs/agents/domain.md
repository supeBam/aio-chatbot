# 领域文档规则

工程 Skills 探索本项目时，按以下规则读取领域文档。

## 探索前读取

- 如果根目录存在 `GLOSSARY.md`，先读取它。
- 如果根目录存在 `GLOSSARY-MAP.md`，按映射读取与当前主题相关的 Glossary。
- 读取 `docs/adr/` 中与当前工作相关的决策记录。
- 如果这些文件不存在，继续工作，不要因此中断或要求提前创建。
- 在术语或设计决策明确后，再按需创建领域文档。

## 文档布局

本项目采用单一上下文布局：

- 根目录 `GLOSSARY.md` 记录领域术语。
- `docs/adr/` 保存架构决策记录。

## 术语与决策

- 输出中使用 `GLOSSARY.md` 定义的术语，避免使用该文件明确排除的同义词。
- 如果某项工作与现有 ADR 冲突，明确指出冲突，不要静默覆盖原决策。
